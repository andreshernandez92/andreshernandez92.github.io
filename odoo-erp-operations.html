The problem

Support requests arrived through different channels and were handled informally, so it was hard to know who owned each request, what was still open, or how users should work with the phone inside Odoo.

Objective: Give every user the correct access and assignments, set up phone usage, and run support through Odoo Helpdesk so every request is a ticket with an owner.

Step by step

1

Set up users and assign them

  • Created and maintained Odoo users.
  • Assigned users to the teams and work they are responsible for, so records land with the right person.
2

Apply access rights by role

  • Gave each user the access their role needs and no more.
  • Kept settings and administration limited to the people who manage the system.

Best practice: least privilege

Start every user with the minimum access for their role and add only what they need. It is much easier than taking access away later.

3

Set up phone usage

  • Configured how users work with the phone in Odoo, so calls are part of the same system as their records.
  • Checked each user's setup so they could use it from day one.
4

Set up the Helpdesk module

  • Installed and configured Odoo Helpdesk with teams and ticket stages that match how support actually works.
  • Set up ticket assignment so new tickets reach the right team members.
  • Made sure every request becomes a ticket with an owner and a status, instead of living in someone's inbox.

Lesson: stages should match real work

If ticket stages do not reflect how the team actually works, people stop updating them. Build the stages with the people who will use them.

Outcome

  • Users set up and assigned to the right teams and work.
  • Phone usage configured for users inside Odoo.
  • Support requests tracked as Helpdesk tickets with clear owners and status.
